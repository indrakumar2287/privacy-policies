🔐 Privacy Policy – Status Vault

Last updated: 26 December, 2025

Status Vault respects your privacy. This Privacy Policy explains how we collect, use, and protect information when you use the Status Vault mobile application.

📱 About the App

Status Vault is a utility app that allows users to view, save, and manage WhatsApp photo and video statuses stored locally on their device.

The app works completely offline and does not require login or account creation.

📂 Data Collection
We do NOT collect:

Personal information (name, email, phone number)

Contacts

Messages or chat content

WhatsApp account data

Location data

Device identifiers

Analytics or tracking data

Any data uploaded to servers

📁 File & Media Access

Status Vault requires storage/media access to:

Read WhatsApp status media files available on your device

Save selected statuses to your local storage (DCIM/StatusVault)

📌 Important:

All media access is local only

Files are never uploaded or shared with external servers

Access is granted only after user permission via Android’s system dialog

🔐 Permissions Used
Permission	Purpose
Read Media (Images / Videos)	To display WhatsApp status files
Storage Access Framework (SAF)	To allow user-approved access to WhatsApp status folder
Internet	Required by Google Play services (no data sent)

The app never accesses hidden data without explicit user consent.

🔄 Data Sharing

Status Vault does not share any data with:

Third-party services

Advertisers

Analytics providers

External servers

All processing happens on your device.

🧹 Data Retention

The app does not store user data

Downloaded statuses remain on the user’s device and can be deleted anytime

No cache or backup is sent outside the device

👶 Children’s Privacy

Status Vault does not target children under 13
The app does not collect any personal information from users of any age.
